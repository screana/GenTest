# 日本の祝日判定モジュール 詳細設計書

- 文書の位置づけ：顧客（発注者）側が作成する詳細設計書であり、単体テスト仕様書作成の入力とする。
- 根拠：公開されている一次情報（法令、内閣府、国立天文台）および対象ライブラリ README のみ。出典の略称は「10. 出典一覧」で定義する。
- 日付表記：本書の日付は ISO 8601 形式（YYYY-MM-DD）とし、括弧内は曜日を示す。
- 境界の表記：「A年からB年まで」は A年と B年の両方を含む。「A年以降」は A年を含む。「A年まで」は A年を含む。

---

## 1. 概要

### 1.1 目的

- 本モジュールは、与えられた日付が日本の「国民の祝日」または法律に基づく休日に当たるかを判定する。（README）
- 本モジュールは、祝日・休日の名称を返す。（README）
- 本モジュールは、指定した年・月・期間に含まれる祝日・休日の一覧を返す。（README）

### 1.2 対象範囲

- 本書が判定仕様を定める期間は、1948-07-20 から 2027-12-31 まで（両端を含む）とする。（祝日法 附則第1項、README）
- 1948-07-20 は祝日法の公布日かつ施行日である。（祝日法 附則第1項、e-Gov 法令情報「公布日 1948-07-20」）
- 2027年までの祝日は内閣府の公表に基づくことを README が明記している。（README）
- 2028年以降の日付についての判定結果は、内閣府の公表がないため本書では正しさを定めない。（README）
- 1948-07-19 以前の日付の扱いは「9. 未定義事項」に記載する。
- 判定の対象は、祝日法に定める「国民の祝日」、祝日法第3条第2項の休日（振替休日）、同第3項の休日（国民の休日）、および個別の法律で定めた臨時の休日とする。（祝日法 第2条・第3条、各休日法）
- 土曜日・日曜日であること自体は、祝日・休日の判定に含めない。（祝日法 第3条）
- README に記載のある独自休日の追加・削除（`register` / `unregister`）とクラス API（`JPHoliday`）は、本書の対象外とする。（README）

## 2. 用語の定義

- 「祝日法」とは、国民の祝日に関する法律（昭和23年法律第178号）をいう。（祝日法）
- 「国民の祝日」とは、祝日法第2条に名称と日付が定められた日をいう。（祝日法 第1条・第2条）
- 「振替休日」とは、国民の祝日が日曜日に当たるときに、祝日法第3条第2項により休日となる日をいう。（祝日法 第3条第2項、内閣府「国民の祝日について」）
- 「国民の休日」とは、前日および翌日が国民の祝日である日のうち、祝日法第3条第3項により休日となる日をいう。（祝日法 第3条第3項、内閣府「国民の祝日について」）
- 「臨時の休日」とは、祝日法以外の個別の法律により、特定の年の特定の日を休日とした日をいう。（各休日法）
- 「特例」とは、特定の年に限り、祝日法第2条の日付を別の法律で読み替えたものをいう。（五輪特措法）
- 「ハッピーマンデー」とは、国民の祝日の日付を「◯月の第N月曜日」と定める方式の通称をいう。本書では法律上の定義として扱わず、便宜上の呼称とする。（平成10年改正法、平成13年改正法）
- 「第N月曜日」とは、その月の1日から数えてN回目に現れる月曜日をいう。（祝日法 第2条）
- 「春分日」「秋分日」とは、太陽の黄経がそれぞれ0度・180度となる瞬間を含む日（日本標準時）をいう。（国立天文台「春分の日・秋分の日」）
- 「祝日等」とは、本書において、国民の祝日・振替休日・国民の休日・臨時の休日の総称をいう。

## 3. 国民の祝日の判定仕様

### 3.1 共通事項

#### 3.1.1 施行日

- 祝日法の施行日は 1948-07-20 である。（祝日法 附則第1項）
- 1948年に国民の祝日となる日は、1948-07-20 以降の日に限る。（祝日法 附則第1項）
- したがって、1948年の国民の祝日は 1948-09-23 秋分の日、1948-11-03 文化の日、1948-11-23 勤労感謝の日の3日である。（祝日法 第2条・附則第1項、国立天文台 暦象年表）

#### 3.1.2 名称

- 祝日名の文字列は、内閣府の表記（内閣府CSV・内閣府「国民の祝日について」）に合わせる。（内閣府CSV）
- 名称には空白や括弧を含めない（例：「海の日」。法律本文中の「海　の　日」のような字間の空白は含めない）。（内閣府CSV）
- 各祝日の名称は、その日付時点で施行されていた祝日法の条文上の名称とする。（祝日法 第2条、各改正法）

#### 3.1.3 日曜日・土曜日との関係

- 国民の祝日が日曜日に当たっても、その日は国民の祝日である。（祝日法 第3条第1項）
- 国民の祝日が土曜日に当たっても、その日は国民の祝日である。（祝日法 第3条第1項）
- 国民の祝日が土曜日に当たる場合、振替休日は発生しない。（祝日法 第3条第2項）

### 3.2 元日

#### 3.2.1 日付

## 4. 春分の日・秋分の日

### 4.1 法律上の定義

- 春分の日は「春分日」である。（祝日法 第2条）
- 秋分の日は「秋分日」である。（祝日法 第2条）
- 祝日法は春分日・秋分日の具体的な月日を定めていない。（祝日法 第2条）
- 春分日・秋分日は、太陽の黄経が0度・180度となる瞬間を含む日である。（国立天文台「春分の日・秋分の日」）
- 春分の日・秋分の日の日付は、国立天文台が前年2月に官報で公表する暦要項により公表される。（内閣府「国民の祝日について」、国立天文台 暦要項）
- 本モジュールは、春分の日・秋分の日を 4.2 の一覧の日付で判定する。（内閣府CSV、国立天文台 暦象年表）

### 4.2 日付一覧（1948年〜2027年）

## 5. 振替休日

### 5.1 適用開始時期

- 振替休日の制度は、昭和48年改正法により祝日法第3条第2項として追加された。（昭和48年改正法）
- 昭和48年改正法の施行日は、公布日の 1973-04-12 である。（昭和48年改正法 附則第1項）
- 1973-04-11 以前（同日を含む）に日曜日に当たった国民の祝日には、振替休日は発生しない。（昭和48年改正法、内閣府CSV）
- 例：1973-02-11（日）建国記念の日の翌日 1973-02-12 は振替休日ではない。（内閣府CSV）
- 最初の振替休日は 1973-04-30（月）である。（内閣府CSV）

### 5.2 1973-04-12 から 2006-12-31 までのルール

- 国民の祝日が日曜日に当たるときは、その翌日を休日とする。（昭和48年改正法による祝日法 第3条第2項）
- この期間の振替休日は、常に日曜日の翌日（月曜日）である。（昭和48年改正法）

### 5.3 2007-01-01 以降のルール

- 国民の祝日が日曜日に当たるときは、その日後においてその日に最も近い「国民の祝日」でない日を休日とする。（祝日法 第3条第2項〔平成17年改正法による改正〕）
- 日曜日の翌日以降に国民の祝日が連続する場合、振替休日はその連続が終わった翌日になる。（祝日法 第3条第2項）
- 例：2008-05-04（日）みどりの日の振替休日は、5-05 がこどもの日のため 2008-05-06（火）である。（内閣府CSV）
- 例：2009-05-03（日）憲法記念日の振替休日は、5-04・5-05 が祝日のため 2009-05-06（水）である。（内閣府CSV）
- 改正の施行日は 2007-01-01 である。（平成17年改正法 附則）

### 5.4 臨時の休日・特例との関係

- 2019年の天皇の即位の日・即位礼正殿の儀の行われる日は、振替休日の適用において国民の祝日として扱う。（即位休日法 附則第2条第1項）
- 2020年・2021年の特例で移動した海の日・スポーツの日・山の日は、移動後の日付で振替休日の判定を行う。（五輪特措法 第29条・第32条第2項、内閣府「国民の祝日について」）
- 例：2021-08-08（日）山の日の振替休日は 2021-08-09（月）である。（内閣府「国民の祝日について」）

### 5.5 名称

- 振替休日の名称は、README の例に従い「元の国民の祝日の名称」＋半角スペース＋「振替休日」とする。（README：2017-01-02 → '元日 振替休日'）
- 「元の国民の祝日」とは、その振替休日を発生させた、日曜日に当たった国民の祝日をいう。（祝日法 第3条第2項）
- 例：2017-01-02 の名称は「元日 振替休日」である。（README）
- 内閣府CSV では振替休日を「休日」と表記するが、本モジュールは README の表記に従う。（README、内閣府CSV）

## 6. 国民の休日

### 6.1 適用開始時期

- 国民の休日の制度は、昭和60年改正法により祝日法第3条第3項として追加された。（昭和60年改正法）
- 昭和60年改正法の施行日は、公布日の 1985-12-27 である。（昭和60年改正法 附則）
- 最初の国民の休日は 1988-05-04（水）である。（内閣府CSV）

### 6.2 1985-12-27 から 2006-12-31 までのルール

- 前日および翌日が国民の祝日である日は、休日とする。（昭和60年改正法による祝日法 第3条第3項）
- ただし、日曜日に当たる日は国民の休日としない。（昭和60年改正法による祝日法 第3条第3項）
- ただし、振替休日に当たる日は国民の休日としない（その日は振替休日となる）。（昭和60年改正法による祝日法 第3条第3項）
- 土曜日に当たる日は国民の休日となる（例：1991-05-04（土））。（昭和60年改正法、内閣府CSV）
- 例：1986-05-04 は日曜日のため国民の休日ではない。（昭和60年改正法、内閣府CSV）
- 例：1987-05-04（月）は憲法記念日（5-03、日）の振替休日であり、国民の休日ではない。（昭和60年改正法、内閣府CSV）

### 6.3 2007-01-01 以降のルール

- 前日および翌日が国民の祝日である日（国民の祝日でない日に限る）は、休日とする。（祝日法 第3条第3項〔平成17年改正法による改正〕）
- 例：2026-09-22（火）は、9-21 敬老の日と 9-23 秋分の日に挟まれるため国民の休日である。（内閣府「国民の祝日について」）

### 6.4 臨時の休日との関係

- 2019年の天皇の即位の日・即位礼正殿の儀の行われる日は、国民の休日の適用において国民の祝日として扱う。（即位休日法 附則第2条第1項）
- このため 2019-04-30（火）と 2019-05-02（木）は国民の休日である。（即位休日法 附則第2条第1項、内閣府CSV）

### 6.5 名称

- 国民の休日の名称文字列は、README・法律のいずれにも定めがないため「9. 未定義事項」とする。
- 参考：内閣府CSV では国民の休日を「休日」と表記している。（内閣府CSV）
- 参考：内閣府「国民の祝日について」では「祝日法第3条第3項に規定する休日」と表記している。（内閣府「国民の祝日について」）

## 8. 公開インタフェース

### 8.1 共通事項

#### 8.1.1 引数の日付

- 日付を受け取る引数には `datetime.date` または `datetime.datetime` を渡せる。（README）
- `datetime.datetime` を渡した場合、時刻部分を無視し、日付部分で判定する。（README）
- 例：`datetime.datetime(2017, 1, 1, 1, 1, 1)` は 2017-01-01 と同じ結果になる。（README）

#### 8.1.2 戻り値の日付

- 一覧を返す関数の要素の日付は `datetime.date` 型である。（README）
- `between` に `datetime.datetime` を渡した場合も、要素の日付は `datetime.date` 型である。（README）

#### 8.1.3 一覧の要素

- 一覧を返す関数は、`(日付, 名称)` のタプルのリストを返す。（README）
- 一覧に含まれる日は、国民の祝日・振替休日・国民の休日・臨時の休日のすべてである。（README「元日 振替休日」の例、1.2）
- 一覧は日付の昇順である。（README の出力例）
- 該当する祝日等がない場合の戻り値は「9. 未定義事項」とする。

#### 8.1.4 1日に1つの名称

- 国民の祝日に当たる日は振替休日にならない。（祝日法 第3条第2項）
- 2007年以降、国民の祝日に当たる日は国民の休日にならない。（祝日法 第3条第3項）
- 2006年以前、振替休日に当たる日は国民の休日にならない。（昭和60年改正法による祝日法 第3条第3項）
- 臨時の休日（7.1・7.4〜7.7）は、いずれも国民の祝日・振替休日・国民の休日と重ならない。（内閣府CSV）
- したがって、1948-07-20〜2027-12-31 の各日について、祝日等の名称は高々1つである。（祝日法 第3条、内閣府CSV）

### 8.2 is_holiday(date) -> bool

- 引数 `date` が祝日等に当たる日なら `True` を返す。（README）
- 引数 `date` が祝日等に当たらない日なら `False` を返す。（README）
- 振替休日に当たる日は `True` を返す（例：2017-01-02）。（README）
- 国民の休日に当たる日は `True` を返す。（祝日法 第3条第3項、6章）
- 臨時の休日に当たる日は `True` を返す。（各休日法、7章）
- 土曜日・日曜日であっても、祝日等でなければ `False` を返す。（祝日法 第3条）
- 例：2017-01-01 → `True`、2017-01-02 → `True`、2017-01-03 → `False`。（README）

### 8.3 is_holiday_name(date) -> str | None

- 引数 `date` が国民の祝日なら、3章・7.2・7.3 に定める祝日名を返す。（README、内閣府CSV）
- 引数 `date` が振替休日なら、5.5 に定める名称を返す。（README）
- 引数 `date` が 7.4〜7.7 の臨時の休日なら、各節に定める名称を返す。（内閣府CSV）
- 引数 `date` が祝日等に当たらない日なら `None` を返す。（README）
- `is_holiday_name(date)` が `None` でないことと `is_holiday(date)` が `True` であることは一致する。（README）
- 例：2017-01-01 → '元日'、2017-01-02 → '元日 振替休日'、2017-01-03 → `None`。（README）

### 8.4 year_holidays(year: int) -> list[tuple[date, str]]

- 引数 `year` の1月1日から12月31日までの祝日等を返す。（README）
- 戻り値は日付の昇順である。（README）
- 各要素の名称は、その日付に対する `is_holiday_name` の値と同じである。（README）
- 例：`year_holidays(2017)` は 17 件を返し、その内容は README の出力例と同じである。（README）
- README の 2017年の出力例：2017-01-01 元日、2017-01-02 元日 振替休日、2017-01-09 成人の日、2017-02-11 建国記念の日、2017-03-20 春分の日、2017-04-29 昭和の日、2017-05-03 憲法記念日、2017-05-04 みどりの日、2017-05-05 こどもの日、2017-07-17 海の日、2017-08-11 山の日、2017-09-18 敬老の日、2017-09-23 秋分の日、2017-10-09 体育の日、2017-11-03 文化の日、2017-11-23 勤労感謝の日、2017-12-23 天皇誕生日。（README）

### 8.5 month_holidays(year: int, month: int) -> list[tuple[date, str]]

- 引数 `year` 年 `month` 月の1日から末日までの祝日等を返す。（README）
- 戻り値は日付の昇順である。（README）
- 各要素の名称は、その日付に対する `is_holiday_name` の値と同じである。（README）
- 例：`month_holidays(2017, 5)` は [(2017-05-03, '憲法記念日'), (2017-05-04, 'みどりの日'), (2017-05-05, 'こどもの日')] を返す。（README）

### 8.6 between(start_date, end_date) -> list[tuple[date, str]]

- 引数 `start_date` から `end_date` までの期間の祝日等を返す。（README）
- `start_date` の日付が祝日等なら、その日を結果に含める。（README：2017-01-01 開始の例で 2017-01-01 元日を含む）
- `end_date` の日付が祝日等なら、その日を結果に含める。（README：2017-05-03 終了の例で 2017-05-03 憲法記念日を含む）
- 戻り値は日付の昇順である。（README）
- 引数に `datetime.datetime` を渡した場合、時刻部分を無視して日付部分で期間を判定する。（README：`datetime(2017,1,1,3,15,0)`〜`datetime(2017,5,3,12,30,12)` の例で 2017-01-01 と 2017-05-03 を含む）
- 例：`between(date(2017,1,1), date(2017,5,3))` は 7 件 [元日、元日 振替休日、成人の日、建国記念の日、春分の日、昭和の日、憲法記念日] を返す。（README）

### 8.7 判定の優先順位

- 8.1.4 のとおり、対象期間内で1日に複数の祝日等が重なることはないため、名称の優先順位は本書では定めない。（祝日法 第3条、内閣府CSV）
- 国民の祝日の判定には、その日付時点で施行されていた条文を用いる（3章の期間区分）。（祝日法、各改正法の附則）
- 2020年・2021年は、祝日法第2条の日付より五輪特措法の特例の日付を優先する。（五輪特措法 第29条・第32条第2項）
- 振替休日・国民の休日の判定は、特例適用後の国民の祝日と、即位休日法により祝日として扱う日を基に行う。（祝日法 第3条、五輪特措法、即位休日法 附則第2条）

### 8.8 README と本書の関係

- 本書の対象関数のインタフェースは README の「Functions」節と矛盾しない。（README）
- 振替休日の名称は、内閣府CSV（「休日」）ではなく README（「元日 振替休日」形式）に合わせた。（README）
- README は `holidays`・`register`・`unregister` 等も記載しているが、本書の対象外とする。（README）

- 9.3.5 `month` に 1〜12 以外の値を渡したときの挙動。
- 9.3.6 `between` で `start_date` が `end_date` より後の日付のときの挙動（空リストか、例外か、入れ替えるか）。
- 9.3.7 `between` で `start_date` と `end_date` が同じ日付のときの挙動（8.6 の端点を含む規則から1日分の結果になると読めるが、README に例はない）。
- 9.3.8 `between` で `start_date` と `end_date` の型が異なる（一方が `date`、他方が `datetime`）ときの挙動。
- 9.3.9 `datetime.date` のサブクラス（`datetime.datetime` 以外）を渡したときの挙動。

### 9.4 戻り値に関する事項

- 9.4.1 該当する祝日等がない場合に一覧系関数が空リストを返すか（README に例はない）。
- 9.4.2 一覧系関数の戻り値が `list` 型であること以外の型（イテレータ、タプル等）を許容するか。
- 9.4.3 一覧の要素のタプルが名前付きタプル等であってよいか。
- 9.4.4 戻り値のリストを呼び出し側が変更したときに、次回以降の呼び出し結果へ影響するか。

### 9.5 その他

- 9.5.1 `register` で独自休日を登録した状態での各関数の挙動（本書の対象外）。
- 9.5.2 独自休日と国民の祝日が同じ日に重なった場合の名称の優先順位（本書の対象外）。
- 9.5.3 処理性能（応答時間、`between` に長期間を渡したときの上限）。
- 9.5.4 スレッドセーフ性。
